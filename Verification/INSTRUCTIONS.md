# Инструкции по Верификации

## Зависимости
- Python 3.x
- Библиотеки: pandas, matplotlib (установите: pip install pandas matplotlib)

## Запуск Скрипта
1. Перейдите в папку Verification/.
2. Запустите: python final_verification.py
3. Скрипт сгенерирует график final_verification_corrected_plot.png.

## Данные

- Исходные данные находятся в поддиректории `/data`.
- Константы: α=39600, β=0.29, γ₀=75 (из эксперимента Nature, 2024).
